# Проверка пакета 2026.10.05-preview.1

Проверен рабочий каталог `C:\Fusion_Local`. Публикация на GitHub, commit и tag не выполнялись.

## Сравнение состава

- Файлы клиента сверены с исходным `FULL-PATCH-MANIFEST.json`: все имевшиеся файлы соответствовали SHA-256. Отсутствовал только старый `README-FULL-PATCH.txt`; его заменили актуальные README, CHANGELOG и BUGREPORT, манифест пересобран.
- Клиентские Python-модули, DLL и manifest-файлы совпали с установленной локальной версией Fusion. Неподтверждённая экспериментальная сборка изменения STEP не включена.
- Проверены совпадение ключей локального канала в двух интерфейсах и соответствующих конфигурациях, целостность вложенного OfflineJS.zip и отсутствие пользовательских файлов в составе.
- Серверные исполняемые файлы, API, зависимости и тесты совпали с подготовленным серверным пакетом. Новый README заменяет устаревшее описание; в Caddyfile добавлен `default_sni`, ранее доступный лишь через отдельный исправляющий скрипт.
- Добавлены `.gitattributes` с LF для shell-скриптов и `.gitignore` для приватных/сгенерированных данных. Дополнены исключения Docker-контекста.

## Проверки

- Сервер: 6 тестов прошли; в локальном тестовом окружении есть предупреждение Starlette об устаревающем использовании httpx. Предупреждение не вызвало отказа тестов.
- Клиент: 34 Python-проверки обработчиков, очереди, каталога, экспорта и синхронизации прошли в рабочем тестовом наборе разработки. Этот набор не является частью устанавливаемого клиентского патча.
- Реальный запуск после очистки каталога: размер 116 026 493 → 1 564 877 байт, этап загрузки каталога около 51 → 0,15 с. Эти цифры относятся к одной локальной установке.
- Для релиза формируются новый файловый манифест, проверенный ZIP и отдельная SHA-256 архива.

## Что не подтверждено

- Успешный экспорт RC в STEP; проблема остаётся открытой.
- Все комбинации открытия/изменения/сохранения экспортированных F3D в интерфейсе и полного обмена между двумя ПК.
- Новое развёртывание Docker/Caddy на VPS, TLS по IP/домену и восстановление резервной копии в рамках этой проверки.
- Пересборка нативных DLL из данного репозитория: `Client` — готовый дистрибутив патча; C++-исходники и SDK сборки DLL сюда не включены. Для установки они не нужны.

Инструкции и описание релиза отражают эти ограничения; пакет обозначен как предварительный.
