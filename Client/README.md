# Клиент Fusion Local — 2026.10.07-preview.1

Патч интерфейса и локального файлового хранилища Fusion Portable **2703.1.20 x64 300726**. Это дополнение к существующей сборке, а не установщик Fusion. Для официальной онлайн-версии и других сборок пакет не проверен; проверка версии встроена в обработчики каталога и экспорта.

Выпуск предварительный. Ошибка экспорта всей модели в STEP исправлена; поддержаны также IGES, SAT, SMT, STL и 3MF. См. [BUGREPORT.md](BUGREPORT.md). Полный перечень изменений — [CHANGELOG.md](CHANGELOG.md).

## Содержимое

| Путь | Назначение |
|---|---|
| `bin/OfflineJS/OfflineJS.zip` | Изменённая левая панель данных: локальные папки и файловые операции, проверки синхронизации |
| `bin/FusionCDEHostApps/fusion-home-tab/` | Главное окно: локальные модели, корзина, скрытие примеров |
| `PortableData/Roaming/Autodesk/Autodesk Fusion 360/API/AddIns/HomeModels/` | Дополнение, локальный канал интерфейса, фоновые задачи и события документов |
| `.../AddIns/LocalFolders/` | Работа с каталогом, экспортом F3D, аккаунтом, синхронизацией, очередью и штатным меню часов |
| `.../LocalFolders/NativeServerMenu.dll` | Элементы управления сервером внутри штатного выпадающего меню |
| `.../LocalFolders/ProjectExportUI3.dll` | Сохранение F3D в проект и исправление экспорта всей модели в штатном окне |
| `.../LocalFolders/ServerIcons/` | Значки подключения |
| `FULL-PATCH-MANIFEST.json` | Размер и SHA-256 каждого файла пакета, кроме самого манифеста |

Архив не содержит моделей, каталогов пользователя, корзины, паролей, сертификатов или серверных сессий. Файлы `config.json` содержат только настройки локального канала интерфейса. Менять их отдельно от файлов интерфейса нельзя.

## Установка и обновление

1. Сохраните открытые модели. Если обычное сохранение недоступно, экспортируйте изменённую модель в отдельный `.f3d` на компьютер.
2. Полностью закройте Fusion. Проверьте в диспетчере задач, что `Fusion360.exe` завершён.
3. Скопируйте всю папку `FusionPortable` в резервное место. Отдельно сохраните `%USERPROFILE%\AppData\Local\FusionPortableCloud`, если нужен откат настроек подключения на этом же пользователе Windows.
4. Распакуйте **содержимое клиентского ZIP** непосредственно в `FusionPortable`, согласившись на замену. Папки `bin` и `PortableData` должны объединиться с существующими. Не создавайте вложенную `FusionPortable/Client`.
5. При установке из репозитория копируйте содержимое `Client`, а не корень репозитория. `Server` в Fusion копировать не нужно.
6. Запустите обычный `FusionPortableLauncher.exe`. Если дополнение не загрузилось, в окне «Сценарии и дополнения» проверьте запуск `HomeModels` и его запуск при старте. Не запускайте старые установщики поверх этого пакета.

При обновлении авторизация и локальные модели сохраняются. Для нового ПК потребуется отдельный вход: защищённые Windows данные авторизации нельзя переносить между пользователями простым копированием.

## Локальная работа

- На главном экране список локальных моделей показывает модели из рабочих проектов. Открывайте модель из списка; в левой панели доступны папки проекта.
- ПКМ по модели: переименование, перемещение, удаление. Закройте модель перед изменением её записи или удалением.
- ПКМ по папке: переименование или удаление папки с содержимым; удалению предшествует подтверждение и резервная копия.
- Во вкладке «Удалённое» можно восстановить модель в исходную структуру либо окончательно удалить локальную копию из корзины. Если исходный проект отсутствует, восстановление может требовать его возвращения. Окончательное удаление локальной корзины не является командой очистки серверной истории.
- Для экспорта компонента в рабочую область выберите Fusion `.f3d`, включите «Сохранить в локальный проект (.f3d)» и выберите папку штатным полем. При подключении новая модель ставится на синхронизацию.
- STEP — отдельный файл на компьютере, а не синхронизируемая редактируемая модель проекта. Ошибка экспорта всей модели исправлена в этом выпуске.

## Подключение к своему серверу

Сначала установите сервер из папки `Server` и создайте аккаунт. Аккаунт нашего сервера не является аккаунтом Autodesk; логин Linux `root` вводить в Fusion не требуется.

1. Нажмите **часы справа вверху**. В штатном выпадающем меню находятся управление подключением, режим офлайн и текущий статус обмена.
2. Укажите IP или HTTPS-адрес сервера, логин созданного аккаунта и пароль.
3. Для собственного сертификата по IP укажите полный путь к `client-ca.crt`, полученному с вашего VPS по SSH/SCP. Для публичного сертификата поле оставьте пустым. Сертификат должен оставаться по указанному пути.
4. Подключитесь. Часы зелёные при подключении и красные при отключении. Здесь же отображаются текущий файл, этап и доступный прогресс передачи.

HTTP и отключение проверки сертификатов не поддерживаются. Адрес, логин, пароль и токен сохраняются с защитой DPAPI текущего пользователя Windows. Вход на другом ПК отзывает прежнюю сессию: первый ПК переходит офлайн после проверки сессии или следующего запроса и показывает уведомление. Сохранённые данные входа остаются для быстрого повторного подключения. Проверка сессии при работе онлайн выполняется примерно каждые 10 секунд.

## Синхронизация и офлайн-режим

- При запуске с сохранённой активной сессией выполняется фоновая проверка подключения: одна попытка, сетевой тайм-аут 3 секунды, без повторов. DNS и другие системные этапы не имеют гарантированного общего трёхсекундного предела.
- После подключения начинается фоновая синхронизация. Сохранение модели и зарегистрированные файловые операции ставят изменения в очередь. Кнопка обновления левой панели запускает обмен вручную.
- В офлайне операции остаются на диске. Запросы обмена не выполняются; после потери связи нужно нажать «Подключиться», чтобы возобновить работу. Очередь переживает перезапуск программы.
- Файлы, ожидающие загрузки более новой версии, блокируются для открытия и отображаются недоступными. При конфликте независимых изменений обеих копий автоматическая перезапись отменяется; объединения геометрии и отдельного окна разрешения конфликтов нет.
- Удаление после установки поддержки очереди переносит серверный файл в серверную корзину. Старые удаления, сделанные до этого механизма, не воспроизводятся автоматически.
- Переименование и перемещение записываются в метаданные модели на сервере. Полное двустороннее обновление структуры уже существующих моделей и синхронизация пустых папок не гарантируются. Для загрузки моделей в новый проект создайте на принимающем ПК корневой проект с соответствующим именем.
- Поддерживаемый рабочий сценарий — модели F3D. Синхронизация не является резервным копированием сборок со всеми внешними зависимостями; F3Z, связанные документы и специальные типы данных отдельно не проверены.

## Где находятся данные

Относительно `FusionPortable`:

```text
PortableData/Local/Autodesk/Autodesk Fusion 360/LOCALWORKSPACE01/
  NsCloudBrowserCache_local.dat    — каталог проектов и моделей
  W.login/F/                      — файлы моделей и служебные файлы
  LocalFoldersBackups/             — резервные копии операций и локальная корзина
FolderPatchBackup/                — резервные копии установок и исправлений
```

Настройки нашего сервера находятся в `%USERPROFILE%\AppData\Local\FusionPortableCloud`:

- `profile.bin`, `session.bin` — защищённые данные входа и сессия;
- `offline.flag` — приостановка обмена;
- `pending-sync.json` — очередь сохранений;
- `model-operations.json` — операции, привязанные к серверу и аккаунту;
- `sync.bin` — состояние сравнения версий;
- `panel.log`, `native-menu.log` — диагностические журналы.

Не переименовывайте физические F3D и не редактируйте каталог вручную: интерфейс использует внутренние идентификаторы. UUID в физическом имени файла нормален; его появление вместо имени модели в интерфейсе относится к известным проблемам регистрации документа.

## Проверка после установки

На тестовой модели проверьте открытие, изменение и сохранение; создание и переименование папки; перемещение и удаление модели с последующим восстановлением. Затем переключитесь офлайн, измените тестовую модель и подключитесь обратно: должен появиться статус фонового обмена. Не используйте единственную копию важной модели для проверки нового выпуска.

Если запуск снова замедлился, проверьте размер каталога и журнал `logs/AppLogFile*.log`. Очистка повторяющихся служебных записей выполняется при работе с каталогом; после обновления старого раздутого каталога первый запуск ещё может быть медленным. Сбой с оставшимся `NsCloudBrowserCache_local.reload-recovery` требует при закрытом Fusion сохранить обе копии и восстановить полный каталог из recovery; не удаляйте recovery вслепую.

Для отката закройте Fusion и восстановите резервную копию изменённых файлов программы. Каталог и модели восстанавливайте согласованным набором из одной резервной копии, если после установки они менялись.

При сообщении об ошибке приложите версию пакета, последовательность действий, режим подключения, точный текст ошибки и журналы соответствующего времени. Не прикладывайте `profile.bin`, `session.bin`, пароли, приватные TLS-ключи или модели без разрешения владельца.

## Экспорт всей модели

Откройте «Файл → Экспорт» либо нажмите ПКМ по корневой модели и выберите «Экспорт». Укажите формат, имя и папку на компьютере, затем нажмите «Экспортировать».

Для STEP, IGES, SAT, SMT, STL и 3MF изменения автоматически сохраняются перед конвертацией. Если модель ещё ни разу не сохранялась, сначала сохраните её в локальный проект. При ошибке сохранения экспорт останавливается, чтобы не выдать устаревший результат.

Используется тот же сохранённый F3D через временную жёсткую ссылку; отдельная F3D-копия не создаётся. Хранилище модели должно поддерживать жёсткие ссылки (например, NTFS). Экспорт отдельных компонентов остаётся штатным; остальные форматы не изменены.
