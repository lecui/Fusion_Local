# Изменения клиентского патча

## 2026.10.07-preview.1 — исправление экспорта всей модели

- Исправлен отказ переводчика при экспорте всей модели из локального проекта через «Файл → Экспорт» и ПКМ по корневой модели.
- Перед конвертацией сохраняются изменения в исходном F3D. Новый документ для конвертации открывается через жёсткую ссылку на этот же файл: F3D не копируется, сопроводительные файлы не передаются.
- Добавлена поддержка обоих вариантов штатного диалога, в том числе без галочки сохранения в проект и с ранее выбранным STEP.
- Экспорт дочерних компонентов не перехватывается. Сохранение F3D в локальный проект продолжает работать отдельно.
- Проверены STEP, IGES, SAT, SMT, STL и 3MF; пользователь подтвердил работу экспорта в интерфейсе. Другие форматы этим исправлением не затронуты.
- При ошибке сохранения экспорт останавливается; неудачная конвертация не заменяет существующий выходной файл. Новую модель без места сохранения необходимо сначала сохранить в локальный проект.

## 2026.10.05-preview.1 — сводный выпуск

Это перечень накопленных изменений пакета относительно исходного интерфейса используемой portable-сборки, а не обещание совместимости со всеми функциями онлайн-Fusion. Ограничения и неподтверждённые исправления перечислены в BUGREPORT.

### Исправление промежутков после синхронизации

- Повторные ссылки на один локальный файл исключаются перед построением списка карточек, включая пути с разным регистром букв.
- Повторная загрузка файла, отсутствующего на диске, заменяет прежнюю запись каталога и ссылки папки, а не добавляет дубликат.
- Физические модели этим исправлением не удаляются. Вид панели после обновления необходимо проверить при следующем запуске.

### Проекты, папки и модели

- Локальное создание папок через интерфейс панели данных.
- Меню папки: переименование и удаление содержимого с подтверждением.
- Меню модели: переименование, перемещение между доступными папками, удаление.
- Проверки назначения, существования модели, изменения каталога во время операции и конфликтов имён.
- Резервные копии каталога и удаляемых моделей, восстановление при ошибке операции.
- Вкладка «Удалённое»: просмотр локальной корзины, восстановление в исходную структуру, окончательное удаление локальных копий.
- Скрытие раздела примеров в левой панели и вкладки примеров на главном экране; исключение примеров из списка назначений перемещения.
- Главное окно показывает локальные модели из проектов, имена и доступные превью; добавлены открытие и файловые действия.
- Исправлены обработка идентификаторов локальных файлов и чтение формата записей каталога, включая записи без необязательного блока разрешений.
- Передача запросов левой панели через штатный JavaScript/Python-канал для устранения ошибок `Failed to fetch`; главное окно использует согласованный локальный HTTP-канал.
- Доступность модели проверяется по существованию физического файла, отдельно от признаков обновления с сервера.

### Экспорт F3D в проект

- В штатном окне экспорта разрешено сохранение F3D в локальную рабочую область.
- Выбор папки берётся из штатного поля, без отдельного списка директорий.
- Используется штатная кнопка экспорта; экспорт выбранного компонента сохраняет его область выбора.
- Новая модель регистрируется в локальном каталоге и ставится на синхронизацию.
- Для новых экспортов и загрузок создаются отсутствующие служебные файлы локального документа. Имеющиеся служебные файлы Fusion не заменяются автоматически.
- Добавлено восстановление недостающих служебных файлов старых экспортов, нормализация локальной записи и попытка восстановления отображаемого имени.
- Итоговая доступность обычного сохранения и корректность имени после всех сценариев экспорта **ещё требуют проверки в интерфейсе**. Исправление STEP в этот выпуск не входит.

### Сервер, аккаунты и интерфейс подключения

- Подключение к собственному HTTPS-серверу по IP или домену с логином/паролем.
- Поддержка собственного CA через путь к `client-ca.crt`, проверка сертификатов сохраняется.
- Сохранение авторизации с защитой Windows DPAPI; быстрый повторный вход без повторного ввода данных.
- Управление подключением внутри штатного выпадающего меню часов; дублирующее управление на главном экране убрано.
- Часы показывают состояние цветом; меню содержит режим офлайн и сообщения о текущем обмене.
- При отзыве сессии клиент переключается офлайн и уведомляет пользователя; данные повторного входа сохраняются.
- Переносимые пути к библиотекам определяются относительно запущенной сборки вместо жёсткого пути одного ПК.

### Обмен файлами

- Фоновый обмен с сервером; вызовы Fusion API возвращаются на главный поток через события.
- Автоматическая постановка сохранённых моделей в очередь и фоновая синхронизация после подключения.
- Кнопка обновления левой панели запускает принудительную синхронизацию.
- Проверка версии перед открытием, отметка файлов, ожидающих загрузки, и блокировка открытия во время обновления.
- Отображение текущего файла, этапа и прогресса передачи, когда сервер сообщает размер.
- Сверка контрольных сумм и версий; конфликты независимых изменений останавливают автоматическую перезапись.
- Передача имён и путей проекта/папки в метаданных; загрузка новых моделей в локальную структуру при наличии корневого проекта.
- Исправления регистрации полученных моделей, локальных путей и признаков доступности.
- Удаление записывается в очередь, затем выполняется на сервере с ETag и проверкой версии содержимого; повтор после уже выполненного удаления допускает отсутствие файла.
- Восстановление из локальной корзины создаёт явную операцию восстановления серверной записи.
- Модель, удалённая на сервере, не отправляется обратно автоматически только потому, что старая локальная копия ещё существует.
- Переименование/перемещение сохраняются как операции обновления серверных метаданных. Полное зеркалирование структуры на втором ПК не гарантируется.

### Офлайн и запуск

- Очереди сохранений и файловых операций хранятся на диске и переживают перезапуск.
- Операции удаления/восстановления/метаданных привязаны к серверному аккаунту.
- В офлайне запросы обмена не выполняются; очередь исполняется после подключения.
- При недоступности сервера периодические повторы приостанавливаются до ручного подключения.
- Проверка сессии: одна попытка с сетевым тайм-аутом 3 секунды вместо пяти попыток по 12 секунд.
- Исправлено накопление одинаковых служебных записей каталога: при перезагрузке уже загруженные списки не добавляются повторно, а сохранение удаляет только побайтно одинаковые дубликаты распознанного формата.
- Перезагрузка каталога сохраняет полную recovery-копию и восстанавливает её после выполнения загрузки, в том числе при исключении.
- На проверенном ПК каталог уменьшился с 116 026 493 до 1 564 877 байт; соответствующий этап запуска сократился примерно с 51 до 0,15 секунды. Это измерение одной установки, не гарантия скорости любого ПК.

### Комплект поставки

- Полный архив для распаковки с заменой, без запуска старых PowerShell-установщиков.
- Согласованные настройки локального канала и файлов интерфейса.
- Манифест SHA-256, инструкции, перечень изменений и известные ошибки.
- Пользовательские модели, каталоги, авторизация, сертификаты и журналы не включаются.
