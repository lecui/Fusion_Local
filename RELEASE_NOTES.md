# Fusion Local 2026.10.07-preview.1 — исправление экспорта

Исправлена ошибка «Переводчик не смог экспортировать ресурс в файл» при экспорте целой модели из локального проекта.

## Что изменилось относительно предыдущего выпуска

- Работает экспорт всей модели через **«Файл → Экспорт»** и **ПКМ по корневой модели → «Экспорт»**.
- Перед конвертацией сохраняются изменения модели. Для экспорта используется актуальный сохранённый F3D без сопроводительных файлов и без создания F3D-копии.
- Исправлено подключение обработчика к обоим вариантам штатного окна экспорта, включая окно без галочки сохранения в проект.
- Экспорт отдельных компонентов остаётся штатным.

Проверены форматы **STEP, IGES, SAT, SMT, STL и 3MF**. Работа экспорта через интерфейс подтверждена пользователем. Другие форматы в это исправление не включены.

## Обновление

Сохраните модели, полностью закройте Fusion и распакуйте содержимое `FusionLocal-Client-2026.10.07-preview.1.zip` в папку `FusionPortable` с заменой файлов. Затем запустите Fusion обычным способом. Это полный клиентский патч со всеми предыдущими изменениями; промежуточные патчи устанавливать не нужно.

Сервер обновлять для этого исправления не требуется. Модели и данные авторизации в архив не входят. Остальные известные ограничения перечислены в `Client/BUGREPORT.md`.
