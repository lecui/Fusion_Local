# Fusion Local

Клиентский патч Fusion Portable **2703.1.20 x64 300726** и отдельный сервер аккаунтов/файлов для собственного Linux VPS.

Предварительный выпуск **2026.10.05-preview.1**. Незавершённое исправление STEP в выпуск не включено.

- **[Client](Client/README.md)** — патч для копирования поверх `FusionPortable`: локальные модели, корзина, подключение, синхронизация и офлайн-очередь.
- **[Server](Server/README.md)** — Python API, HTTPS-прокси, Docker Compose и скрипты обслуживания VPS.
- **[Все изменения](Client/CHANGELOG.md)**.
- **[Известные ошибки и багрепорт](Client/BUGREPORT.md)**.

Для локальной работы сервер не обязателен. Для синхронизации установите сервер, создайте аккаунт и подключитесь из меню часов в Fusion. Серверный аккаунт не связан с аккаунтом Autodesk.

Установка клиента: сохраните модели, закройте Fusion, сделайте резервную копию `FusionPortable` и распакуйте **содержимое клиентского архива** в эту папку с заменой файлов. Подробная инструкция — в README клиента.

Не копируйте весь репозиторий в папку программы. Модели, пользовательские каталоги, пароли и сертификаты в релиз не входят. Для других сборок Fusion совместимость не заявлена.
